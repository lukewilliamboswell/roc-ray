[.lead]
RocRay is a Roc platform for games, visual tools, and other interactive
programs that draw a frame at a time. Your app keeps its own state and rules;
RocRay supplies drawing, audio, keyboard and mouse input, windows, recording,
files, and networking. This manual takes an app from its first window, through
the features it will reach for as it grows, to the design that holds them
together.

[discrete]
== Choose a path

New to RocRay:: Read <<overview>>, then follow <<getting-started>> to run an
example and write the smallest app. <<examples>> suggests what to read next.
Building an app:: Read <<app-model>> first. It introduces `init!`, `update!`
and `render!`, which every later guide builds on. Then read the guides for the
features you need, in any order: <<input>>, <<drawing>>, <<tasks>>, and so on.
Before your app touches a file, the network, or another program, read
<<permissions>>.
Testing and investigating performance:: <<testing>> covers the pure tests and
unattended runs an app can use. <<observatory>> records what the host did,
cycle by cycle, into a database you can query.
Curious about the design:: <<architecture>> explains the rules the guides
introduce one at a time, and why RocRay chose them.
Contributing to RocRay:: Start with <<contributing>>. <<host-development>>
covers changes to the native host, and <<maintaining>> covers dependencies,
bundles, and releases.
