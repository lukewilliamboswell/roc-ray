[#release-0-12-0]
= RocRay 0.12.0

0.12.0 adds drawing primitives for tessellated geometry and charts, fixes
scissor isolation during offscreen rendering, and restores compatibility with
the latest Roc nightly. Existing application entry points and drawing calls
remain available.

== Drawing

`Draw.Frame` gains `triangles!`, `triangle_fan!`, `triangle_strip!`,
`line_strip!`, `circle_sector!`, `ellipse!`, and `ring!`, with equivalent
`Draw` free functions. Submit geometry computed by your Roc application or a
pure package; the host consumes it during the call and retains no scene.
Triangle topologies accept either winding. Invalid point counts, non-finite
coordinates, and invalid arc parameters fail as programmer errors.

Scissors now belong to the surface on which they were opened. Entering a
render texture suspends its parent's clip, target-local scissors apply only
inside that target, and leaving it restores the parent's clip. This also
works for nested render textures.

== Roc nightly compatibility

Methods on frames, vectors, physics values, and gamepad snapshots are attached
explicitly to their receiver types, preserving their free-function forms.
Windows hosts provide the floating-point runtime marker as a linker fallback,
so both LLVM and native-backend applications link with the latest compiler.
The platform continues to follow the latest nightly without a compiler pin.

== Documentation and downloads

The manual now uses roc-automation's shared renderer, including native Mermaid
figures, static Markdown chapters, and a discovery index. The documentation
site and PDF are built together; API reference generation retains the
platform's phase checks and private-module filtering.

Release documentation downloads are now `roc-ray-0.12.0.pdf` and
`roc-ray-docs-0.12.0.zip`. The zip contains the manual and the API reference
under `api/`. These replace the separate manual and API archives used by
previous releases. The examples archive remains `roc-ray-examples-0.12.0.zip`.

Explicit heading IDs are retained. Autogenerated section anchors change from
Asciidoctor's underscore-prefixed names to hyphenated names, so bookmarks
using those old anchors need updating. Gallery stills link to the original
animated recordings.

The shared nightly compatibility matrix now includes Intel macOS alongside
Apple Silicon macOS, Linux x64, and Windows x64.
