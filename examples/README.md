# RocRay examples

Each directory here is a complete app. Run one from the directory that
contains `examples/`, so its asset paths resolve:

```bash
roc examples/hello_world/main.roc
```

The [example gallery](https://lukewilliamboswell.github.io/roc-ray/manual/#examples)
in the RocRay manual describes every example, what it demonstrates, and a
learning path; its source is [`docs/examples.adoc`](../docs/examples.adoc).
Start with `hello_world`, then `pong`, then `task_sleep`.
